# ACD implement (IDE)

```
npx acd implement
npx acd implement --scenario N
```

Omit `--scenario` to complete remaining numbered scenarios one at a time (red-green-refactor). Pass `--scenario N` to target a single heading in `behavior.feature`.

Follow `.acd/skills/implement-scenario/SKILL.md` if running inside this session instead of the CLI.
