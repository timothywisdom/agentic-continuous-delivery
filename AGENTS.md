# ACD (Agentic Continuous Delivery)

This repository uses the ACD kit. The TypeScript CLI (`acd`, or `npx acd`) is the orchestrator.

- Skills: `acd/skills/`
- Agent rules: `acd/agents/`
- Config: `acd.config.yaml`
- Work items: `.acd/work/<id>/`

Do not use an LLM to decide the next pipeline stage.
